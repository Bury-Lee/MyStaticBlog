# 后世纪·末日档案

> 也许这是一个轮回——童真之神，可能就是新的深渊世界。

---

## 一、后世纪从何而来

### 1.1 传说之后世界的毁灭

传说之后世界经历了几千年迭代之后，科技发达，技术进步，世界被人类所占领，人口达到了夸张的**八千七百亿**。人类的意志足以决定神明的形态，但是资本主义让人类的贪婪越来越严重，人类的灵魂也越来越破碎。

终于，在一次经济危机之后——战争、贫穷、压迫、痛苦、悲伤……无数的痛苦使人类产生了极其共同的极端恶意。于是毁灭世界的神明——**童真之神**出现了。

童真之神是人心中的最本能的欲望，"获得想要的事物"，换句话说就是**物欲和恶意**：这种物欲使人疯狂，而恶意使人伤害别人。而这样的思想还会继续传染，导致越来越多的人类变得贪婪。更糟糕的是，童真的神明在出现之初就已经实现了**自举**。

> 童真之神的力量因为人的绝望而变得越来越强，最后毁灭了这个世界。
>
> 不过讽刺的是，此时代表人类的阶级是资本家，他们的思想就是支配、剥削别人，导致他们立场下的神明也是支配之神，其强度完全不能比——所以童真之神轻易地毁灭了这个世界。

### 1.2 污染的扩散

支配的神明迫不得已重启了起源神明未完成的事物，逃去了**李葬所在的世界**——那个李葬当年用反转仪式回去的、原本的世界。

之后便是后世纪的开端。

童真的神明同化了世界的一部分，世界又回到了像是深渊世界时期那般，开始出现了混沌事物与现象。童真之神开始和世界意志出现交融、侵蚀，使得童真之神也开始变为**世界意志本身**。

因为这些，童真之神也可以跨越世界的限制，污染其他的世界。表现就是不可逆转的灵异、恐怖、玩具等，各种扭曲怪异可怕的现象发生。

> 这导致李葬本来的世界被入侵，出现了诡异，世界基本上毁灭了。（虽然还有非常非常少数的人类在负隅顽抗。）

### 1.3 时间与地点

时间来到 **2021 年**，那一年没有疫情，却发生了比疫情更为可怕的事情。地点是**广东**——故事从一个河边被冲上岸的失忆少年开始。

## 二、末日现象：玩具化

### 2.1 同化机制

世界被一种名为"**玩具化**"的诅咒覆盖：

- 普通人被玩具触碰后，身体扭曲，几分钟后变成玩具的一员
- 被同化者会继续同化其他灵魂——它们不断同化，越滚越多
- 现象表现为不可逆转的灵异、恐怖、玩具等，各种扭曲怪异可怕的现象

### 2.2 玩具的感知

**普通玩具既没有视力，也没有听力，是靠着人的"气息"来追踪人的。**

- 只要离它们远一点，就不会被发觉
- 在封闭空间中，人的气息"如同被困住的烟雾，无法在空间中消散"——此时玩具不需要多久就会锁定目标
- 躲在家具、柜子里可以暂时避开追踪

### 2.3 变异玩具

| 类型 | 特征 |
|------|------|
| **普通玩具** | 木偶、布娃娃等。无视力无听力，靠气息追踪，触碰即同化 |
| **机械玩具熊** | 有**电子眼与视力**（视力范围有限），力量恐怖——一拳能要人命，能掀翻床、沙发等一切障碍。行动较慢，发条声"滴答、咔哒"是它的踪迹 |
| **空间扭曲现象** | 便利店中出现循环空间——通道尽头不是楼梯，而是另一排一模一样的货架，出口消失。物品、灯管位置镜像般重复 |
| **"诡异的巨人"** | 五六层楼高的巨大洋娃娃，犹如巨人一般。连叁玖也畏惧与之交手。水泥路上的深坑，很明显就是这样的破坏力造成的 |

### 2.4 末日景象

- 无数的人偶、布娃娃"追杀"人类
- 路灯被破坏，街道空无一人，带来压抑窒息的感觉
- 很多幸存者已经把便利店里的东西带走
- 玩具被声响、动静吸引，会"密密麻麻地聚集到一起"
- 幸存者所剩无几

## 三、世界观定位：新深渊的轮回

后世纪并非一个独立的宇宙，而是**童真之神的污染扩散到了李葬所在的世界之后的状态**。

三个世界构成一个宏大的轮回：

```
深渊世界 ──解体──→ 传说之后世界 ──毁灭──→ 后世纪（新深渊？）
  │                      │                       │
  │  混沌、痛苦           │  秩序、封闭           │  混乱再临
  │  灵魂在折磨中成长      │  概念神体系           │  玩具化污染
  │  神明 = 痛苦容器       │  人类意志决定神明     │  世界重回深渊般
```

**深渊世界** → 无法无天的混沌，一切基于痛苦和折磨。
**传说之后世界** → 星梦试图创造的秩序世界，但封闭导致毁灭。
**后世纪** → 童真之神的污染让世界"回到了像是深渊世界时期那般"。

> 核心命题：**秩序是否注定走向崩坏？痛苦是否是存在的底层本质？新的深渊是否正在旧世界的废墟上重生？**
