# 李葬 / Bury.Lee（传奇之后）

---

## 📋 基本信息

| 项目 | 内容 |
|------|------|
| **姓名** | 李葬 |
| **英文名** | Bury.Lee |
| **性别** | 男 |
| **种族** | 福瑞 |
| **术属性** | **镜**——极其稀有（约 1% 的人拥有） |
| **师承** | 陈龄（时空的匠人） |
| **最终等级** | 至纯·小成 |
| **武器** | 葬刀（天下名刀之一）、后期另加长枪 |
| **身份** | 异界来客 → 传奇人物 → 退隐学者 |

---

## 👤 外貌

福瑞。前期是师傅送的空间附魔巫师帽（内部有约 1 立方米的存储空间），穿着大衣，没有衣服和裤子（福瑞身上都是毛，在陈龄所在的南方太热了）。后期行军渐多，脚下添了棕色高筒鞋。

---

## 💭 性格

**极端正义**——为了自认为正义且合理的目标不择手段，杀伐果断，深思熟虑。崇尚理智与哲学。

---

## 🔮 能力

| 能力 | 说明 |
|------|------|
| **时空间 + 凝聚剑** | 学到和陈龄一样的战斗模式，最高可以把自己的时间加速到近乎 **100 倍** |
| **镜之铠甲** | 战斗时习惯使用创造镜之铠甲保护自己 |
| **拔刀斩** | 成名绝技——将自身加速到 60 倍以上，刀刃附着吸收动能的"**灭世**"，几乎是无坚不摧 |
| **改进版拔刀斩** | 在长枪上做好时空间标记，先投出长枪；在对方抵挡露出破绽的一瞬间，使用**流影**飞到标记处，展开**域**，使用 60 倍以上加速的拔刀斩。此时刀刃与空气摩擦甚至使刀身变得通红 |

### 装备

- **北华天山帽**：空间附魔巫师帽
- **葬刀**：天下名刀之一，修长而细，坚不可摧，削铁如泥。没有镡，只有一小部分用于连接握把和刀刃，所以刀鞘加以改造，只需拔出一部分，便可以让刀从刀鞘缝隙中脱落，实现拔刀斩。是陈龄的倾力之作，不过刀身相当沉重

### 天下名刀

| 名刀 | 特征 |
|------|------|
| **葬刀** | 陈龄倾力之作，刀身沉重，专为拔刀斩设计 |
| **帝刀（无上帝王剑）** | 集各地能工巧匠、大部分使用铁木打造的刀，方方面面性能达到时代最优，为秦帝持有 |
| **华刀** | 双刃锋利，修长而细，坚不可摧，削铁如泥，比葬刀轻 |
| **鸿刀** | 陈龄自己用的，形似唐横刀 |
| **碎刀·百解** | 天下名刀之一，最大胆的铸造思路——可分离式设计：100 个相同矩形刀片单元串联，每个双面开刃。强力挥砍时刀片逐节断裂飞出，形成扇形弹幕"百解斩"；可激活符文召回重拼，但重组后强度很低，是**只攻不防**的刀 |

---

## 📜 关键经历

- 以现代少年身份被召唤至异世界
- 师从陈龄学习，在此世界学习、成长、战斗，成为中兴人物
- 北战时收留了机械师艾伦·维兰，二人并肩作战
- 退隐后与艾伦·维兰合著《大数物理》

## 📝 备注

- 本档案是**传奇之后世界**的李葬。
- 传说之后世界另有一位同名"李葬"（Bury.Lee）——两者**只是恰好同名**，故事与设定完全独立：传奇之后的李葬退隐后过着平凡生活，传说之后的李葬则成为"神明的神明"并返回了原世界。
