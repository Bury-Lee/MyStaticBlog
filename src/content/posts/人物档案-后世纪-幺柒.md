# 幺柒（17）

> *"幺柒……我叫幺柒……"*

---

## 📋 基本信息

| 项目 | 内容 |
|------|------|
| **姓名** | 幺柒（只记得数字"17"） |
| **性别** | 男 |
| **年龄** | 约 18 岁 |
| **身份** | 失忆少年 / 无证件者 |
| **特征** | 免疫玩具的同化效果；全县无人认识，无任何身份信息 |

---

## 👤 外貌

普通少年。被发现于河边，当时已昏迷很久。

---

## 💭 性格

- 冷静善思，在绝境中能快速制定计划
- 观察力与推理能力突出——能从玩具的行为中反推出"气息追踪"的规则
- 关键时刻有牺牲精神：为给叁玖争取填充棉花的时间，主动以身作饵

---

## 🔮 能力

- **免疫同化**：被玩具碰到后不会变成玩具，但是会“死去”
- 普通人的体力与智力，无特殊战斗能力

---

## 📜 关键经历

| 阶段 | 内容 |
|------|------|
| **医院醒来** | 2021 年，东州一家医院。主任问他名字，他摇摇头："什么都记不起来……"但隐隐约约还记得一个数字，17。"幺柒……我叫幺柒……"说完又晕了过去 |
| **寻找记忆** | 康复后找了份送外卖的活，每次送完一单都会给别人寄一张小卡片，上面是他的照片和电话，想以此找到认识自己的人。但几个月过去，县里被问了个遍，没有一个人认识他，也查不到任何身份信息——他像一个黑户，只能使用一张临时身份证，有一种自己不属于这个世界的感觉 |
| **末日爆发** | 某天清晨，世界突然翻天覆地。他先躲进柜子逃过一劫；下午被一个被追杀的男子牵连而"死掉"，随后被叁玖从玩具堆里救出 |
| **旅馆对话** | 从叁玖口中得知玩具靠"气息"追踪、叁玖能隔绝气息。他迅速整理信息：自己为什么免疫？叁玖为什么认为自己是人？体内的棉花是什么？ |
| **便利店与循环空间** | 与叁玖前往隆江便利店搜集物资，遭遇空间扭曲——货架镜像般重复，出口消失。他推理出气息在封闭空间中无法消散，玩具熊很快会锁定他们 |
| **家具城死战** | 空间缺口将他们转移到家具城。叁玖填充棉花时，幺柒以自己为诱饵拖住机械玩具熊，被飞来的沙发砸中，喷出一口鲜血。叁玖恢复力量后一拳击飞玩具熊，将其消灭 |
| **前往医院** | 幺柒重伤，两人决定前往三公里外的医院；此时大量玩具被声响吸引，正朝他们聚集 |
