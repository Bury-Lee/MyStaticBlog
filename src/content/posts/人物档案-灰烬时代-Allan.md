## 💭 性格

- **高度理性与逻辑思维**：拥有极强的系统分析与工程解决问题能力，能快速理解复杂设备并制定有效方案
- **冷静务实**：在极端陌生和危险的环境中保持清醒，优先考虑生存与安全。最初对 S8 采取囚禁策略，体现其谨慎和风险控制意识
- **耿直单纯**：心思直接，不擅长掩饰或权谋。道歉时会因纯粹的内疚而事后才表达，显得笨拙却真诚
- **责任感强**：虽最初计划囚禁 Stan，但在确认其无害后，冒险修复电力将其救出，并为将他置于险境而真诚道歉
- **知识渊博**：对 21 世纪末的科技、工业体系、实验室设计有深刻了解，能基于常识推断研究所性质
- **反差萌**：严肃认真的工程师形象与容易害羞脸红的性格形成鲜明反差，被 Stan 认为"可爱"

---

## 🔮 能力

- **系统分析与工程能力**：能快速理解复杂设备（如数控系统、备用电源），并制定有效方案（如使用太阳能板 + 自制原电池恢复供电）
- **手搓文明**：从继电器逻辑门电路开始重建计算系统；修复量子内存、训练模型、干细胞培养、自制火箭、修复星环
- **AGI 认知架构**：继承原始 AGI 的思维架构（A 型最接近原始 AGI），天赋卓绝
- **抗辐射**：基因层面强化了差错修复机制

---

## 📜 关键经历

| 阶段 | 内容 |
|------|------|
| **苏醒** | 人类灭亡约 50 年后，中核机密研究所电力意外恢复。A 型改良 AGI 代号 A1 醒来，经历一番博弈后与 S8 成为伙伴，自名 Allan |
| **首次探索** | 带着两天份罐头出发，在鸿县自然保护区首次遭遇太空生物，抵达原子炉附近的城市废墟 |
| **基础重建** | 手搓磁铁 → 低精度 CPU → 训练模型 → 修复量子内存 → 干细胞培养 |
| **克隆循环** | 周期性克隆自身。每一代继承人格底色但不继承记忆 |
| **星环任务** | 首次登环失败，两名克隆体牺牲；第二次成功清除局部区域 |
| **最终献祭** | 第 17 代本体亲自执行最终登环任务，以自身为诱饵引开"母体级"太空生物，手动接通生物线圈。星环重启成功，二人因辐射过量与能量耗尽，在控制台前化为尘埃 |
| **方舟** | 新一代 Allan 与 Stan，建造"方舟-Ω"，驶向银河系旋臂深处 |
