# 星梦 / StarDreamer

> *"永恒的混沌" / 纯白法师 / 第二代宿命的神明*

---

## 📋 基本信息

| 项目 | 内容 |
|------|------|
| **全名** | 星梦（StarDreamer） |
| **别称** | 永恒、纯白法师、永恒的混沌、第二代宿命的神明 |
| **性别** | 男 |
| **种族** | 福瑞（白色毛发） |
| **发色/瞳色** | 白色毛发 / 彩虹色瞳孔 |
| **身份** | 第二代宿命的神明 → 传说之后世界创世者 → 组织 Ø 的"永恒" |
| **状态** | 活跃（跨世界存在） |

---

## 👤 外貌

- 白色福瑞形态，没有头发，有着彩虹般五颜六色的瞳孔
- 戴着白色镶金边的巫师帽，白色长袍，长袍后面印着"∞"符号
- 表情平和，微笑，眼神深邃

---

## 💭 性格

- 平和、温柔、安逸、冷静理性
- 兼具 Allan 的清醒与 Star 的温柔——"既清醒又沉溺，既绝望又温柔，眼里是悲悯的温柔，平静的表情中透露忧伤"
- 有俏皮和恶作剧甚至是抽象的一面
- 其对宿命的理解更接近"**引导可能性**"，而不是替所有人做出选择

---

## 🔮 能力

| 能力 | 说明 |
|------|------|
| **宿命编织** | 操纵时间与概率中最微小的偏差，使事件向特定方向收敛 |
| **创世** | 设计并创造了三维封闭宇宙（传说之后世界） |
| **混沌之魂** | 可穿越时空与宇宙；其本体是一个残缺的混沌世界 |
| **意识侵入（深渊魔法）** | 可进入他人梦境与精神 |
| **跨世界存在** | 能够通过混沌之魂和世界之间的联系留下影响 |
| **世界级视角** | 可能接触世界循环、世界意志和上一轮历史 |

**躯体"白羽"：** 其躯体是本体混沌残缺世界与其他世界的纽带。白羽（前风精灵）性格上和星梦没有太大区别，但受到强烈刺激时，星梦的状态不太稳定，会间接影响到躯体，可能导致一定的不可控行为。白羽也自称为星梦。即使抛开混沌残缺世界不谈，白羽本身也是非常厉害的大法师。

---

## 📜 关键经历

| 时间线 | 事件 |
|-------|------|
| **起源** | 一个在深渊中浑浑噩噩游荡了很久的游魂，阿比斯猛地意识到了自己的存在，回忆起了他的一部分过去——不知道什么时候，突然涌现了**自我之魂** |
| **诞生** | 不断遭受苦难、不断自我救赎，终于认清自我成为神明；此后经历数次大战，化为世界与因果，崩坏了世界**逆流之泉** |
| **融合** | Allan 将 Stan 的灵魂碎片一片一片融入自身灵魂结构，形成星梦——非覆盖非替代，而是共生 |
| **摧毁深渊** | 成为宿命神明后摧毁混乱的深渊世界，驱散迷失灵魂 |
| **创世** | 发现世界若完全由一人意识决定会混乱不堪，放弃神位，设计三维封闭宇宙——传说之后世界诞生 |
| **化身永恒** | 以"永恒"/"纯白法师"身份加入组织 Ø，在人之神明离去的黑暗时代暗中守护人类 |
| **引导李葬** | 在百人行最绝望时以星梦本体现身，开导李葬 |
| **留下权限** | 在《精灵使与魔兽时代》世界留下"混沌残缺世界"与宿命之书——一套跨世界权限的不同表现 |

## 🔗 关系

| 角色 | 关系 | 说明 |

| **北梦** | 患者 / 被引导者 | 为其进行深度催眠治疗 |

---

## 📝 备注

- 星梦的灵魂不太稳定，导致其精神不够稳定
- 作为融合体，星梦的性格是 Allan 和 Star 的结合
- 在《精灵使与魔兽时代》中，星梦并未以完整本体直接降临，而是通过宿命之书和混沌残缺世界产生影响——他究竟是在帮助主角、利用主角，还是在引导某个早已编织好的结局，仍然无法确定
